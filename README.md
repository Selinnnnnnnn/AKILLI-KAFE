# AKILLI-KAFE
Kullanıcıdan sipariş edilen ürünlerin adını, adetini ve birim fiyatını alır. Eğer mutlu saatlerde (Happy Hour) sipariş verilmişse veya kullanıcı kulüp üyesiyse indirim ve tavan fiyat uygular; ardından f-string kullanarak hizalanmış bir kafe fişi basar .
Projede Kullanılan Konular:
input(), int(), float() ile veri alıp tür dönüşümü yapma
if / elif / else ve mantıksal (and, or, not) koşullar ile indirim hesabı yapma
f-string hizalama ({urun:<12}, {tutar:>8.2f}) ve center() ile yıldızlı/çizgili başlık tasarımı
